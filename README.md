# 보면대

PDF 악보를 **연주 날짜·분류별 폴더**로 정리하고, **반 쪽씩 넘기며** 보는 악보 앱입니다.
아이패드, 갤럭시탭, 노트북, 휴대폰 어디서나 브라우저로 열고 홈 화면에 설치해 앱처럼 씁니다.

## 기능

- **폴더 정리**: `20261118 빛고을`처럼 날짜로 시작하는 폴더는 연주로 인식해서
  당일에는 맨 위 **"오늘 연주"** 로, 앞으로 할 연주는 "다가오는 연주", 끝난 건 "지난 연주"로 자동 정렬됩니다.
  `솔로곡`, `실내악`, `오케스트라` 같은 분류 폴더도 자유롭게 만들고 이름을 바꿀 수 있습니다.
- **파일은 하나만**: 같은 악보를 여러 폴더에 넣어도 PDF는 한 번만 저장됩니다.
- **연주 순서**: 폴더 안에서 ▲▼로 곡 순서를 바꾸고, 한 곡이 끝나면 다음 곡으로 바로 넘어갑니다.
- **넘기기 방식**: 한 쪽씩 / **반 쪽씩**(위 절반에 다음 쪽이 먼저 보임) / 두 쪽 펼침(가로 화면).
- **페달 지원**: 블루투스 페이지 터너(AirTurn, PageFlip 등)의 방향키, Page Up/Down, 스페이스 신호를 받습니다.
  페달 없이 화면 좌우 터치나 옆으로 밀기로도 넘어갑니다.
- **악보 넣기**: "+ 악보 넣기"로 파일 고르기, 노트북에서는 끌어다 놓기,
  안드로이드에서는 **카카오톡 → 공유 → 보면대**로 바로 들어옵니다.
- **보내기**: 폴더를 zip으로 묶거나 악보 한 개를 카카오톡 등 다른 앱으로 보낼 수 있습니다.
- **오프라인**: 한 번 열면 인터넷 없이도 실행되고, 악보 보는 동안 화면이 꺼지지 않습니다.

## 기기별 카카오톡 PDF 넣기

| 기기 | 방법 |
|---|---|
| 갤럭시탭·안드로이드 | 크롬에서 앱 설치 후, 카톡 PDF 공유 → **보면대** 선택 |
| 아이패드·아이폰 | 카톡 PDF 공유 → **파일에 저장** → 보면대 "+ 악보 넣기"에서 선택 (웹앱은 iOS 공유 목록에 뜰 수 없음) |
| 노트북 | 받은 PDF를 창에 끌어다 놓기 (크롬/엣지에 설치하면 PDF "연결 프로그램"으로도 열 수 있음) |

## 구조

빌드 과정 없는 순수 HTML/JS입니다.

- `index.html`, `app.css`, `app.js`: 화면과 동작
- `db.js`: IndexedDB 저장소 (악보 정보, PDF 원본, 폴더, 공유받은 파일함)
- `sw.js`: 서비스 워커 (오프라인 캐시, 공유받기)
- `manifest.webmanifest`: 설치 정보, 공유 대상, PDF 파일 연결
- `vendor/`: pdf.js 3.11.174, JSZip 3.10.1
- `samples/`: 예시 악보 PDF

로컬 실행: `python3 -m http.server 8000` 후 http://localhost:8000

## 배포

`.github/workflows/pages.yml`이 GitHub Pages로 배포합니다.
저장소 **Settings → Pages → Source를 "GitHub Actions"** 로 한 번 설정하면 됩니다.

악보는 각 기기 안에만 저장됩니다. 기기끼리 자동 동기화는 아직 없으니, 폴더 메뉴의 "PDF 묶음으로 보내기"로 백업하세요.
